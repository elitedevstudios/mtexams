## Accessibility (WCAG 2.1 AA)

Foundation is strong: every page has `lang`, landmarks (`header`/`nav`/`main`/`footer`), good ARIA (dialog, `aria-live`, grouped controls, `aria-current="page"`), contrast AA/AAA, non-color-only feedback, and TTS with reduced-motion fallback.

| ID | Severity | Finding | Location | Fix |
|---|---|---|---|---|
| A11Y-1 | 🔴 Critical | No skip link — keyboard users tab through nav every page (WCAG 2.4.1) | all 5 HTML pages | Add `<a class="skip-link" href="#main">`, `id="main"` on `<main>` |
| A11Y-2 | 🔴 Critical | Name `#name-input` has no `<label>` (placeholder-only, WCAG 1.3.1); quiz `#answer-input` likewise | modal (all pages), `js/app.js:831` | `visually-hidden` `<label for>` / `aria-label` |
| A11Y-3 | 🔴 Critical | Name modal opens on load with no Escape-to-close / focus trap (WCAG 2.1.1) | `js/app.js` modal logic | Escape handler + trap focus while open |
| A11Y-4 | 🟠 Major | `.sound-toggle` has no `:focus-visible` — invisible focus for keyboard users | `css/navigation.css:66-78` | Mirror global focus style (`base.css:135-138`) |
| A11Y-5 | 🟠 Major | H1 rendered via JS; first heading at load is modal H2 (WCAG 1.3.1) | home/assessments | Lower priority; ensure JS sets an H1 early |
| A11Y-6 | 🟡 Minor | Modal-pop / wave-emoji animations lack `prefers-reduced-motion` override | `css/components.css` | Global rule covers most; add explicit overrides |
| A11Y-7 | 🟡 Minor | `lang="en"` could be `en-JM` (3.1.2) | all pages | Optional |
